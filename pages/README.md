# WisataKu — Aplikasi Tour & Travel

Aplikasi web manajemen paket wisata berbasis PHP & MySQL.

## Teknologi
- PHP 8.x
- MySQL
- Bootstrap 5.3
- Laragon (localhost)

## Cara Install
1. Clone repo ke `C:\laragon\www\tour-travel`
2. Import `database.sql` ke MySQL
3. Sesuaikan `includes/config.php`
4. Akses `http://localhost/tour-travel`
